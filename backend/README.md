# UniGuesserRun Backend

This is the backend service for the UniGuesserRun project.

##

### Requirements

- **.NET SDK:** Version 9.0 
   Download from [dotnet.microsoft.com](https://dotnet.microsoft.com/download)
- Compatible with Windows, Linux, and macOS
- Recommended IDEs: Visual Studio 2022, Visual Studio Code, or JetBrains Rider

## Getting Started

1. **Clone the repository**
2. **Install dependencies**  
   Follow your preferred method (e.g., `dotnet restore` for .NET projects).
3. **Run the backend**
   ```bash
   dotnet run
   ```
