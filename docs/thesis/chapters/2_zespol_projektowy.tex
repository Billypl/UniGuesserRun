\noindent
Podział prac przy tworzeniu aplikacji UniGuesser:

\smallskip
\begin{itemize}
  \item \textbf{Filip Jezierski} - odpowiedzialny za rozwój frontendu aplikacji, obejmujący implementację interfejsu użytkownika, integrację z mapami i mechanizmami geolokalizacji oraz połączenie z backendem, a także konfigurację aplikacji jako Progressive Web App (PWA). Ponadto zajmował się analizą wymagań i planowaniem funkcjonalności, testowaniem interfejsu użytkownika oraz przygotowaniem dokumentacji technicznej dotyczącej warstwy frontendowej.
  \item \textbf{Michał Pawiłojć} - odpowiedzialny za przygotowanie i utrzymanie środowiska projektowego oraz infrastruktury łączącej wszystkie elementy aplikacji. W ramach prac zorganizował repozytorium GitHub, stworzył zasady współpracy i formatowania kodu oraz opracował konfigurację narzędzi wykorzystywanych przez zespół. Przygotował również komplet plików wdrożeniowych opartych o Docker i usprawnił procesy deweloperskie.
      Najważniejsze zadania obejmowały:
      \begin{itemize}
        \item konfigurację i utrzymanie repozytorium projektu na GitHubie,
        \item przygotowanie struktury pracy zespołu, standardów kodowania oraz wytycznych projektowych,
        \item stworzenie środowiska uruchomieniowego aplikacji opartego o Docker i Docker Compose,
        \item integrację backendu, frontendu i bazy danych w jednolitym środowisku developerskim,
        \item automatyzację uruchamiania projektu oraz usprawnienie lokalnego procesu developmentu.
      \end{itemize}

  \item \textbf{Michał Turski} -  odpowiedzialny za projekt i implementację backendu aplikacji. W ramach prac przygotował strukturę wielowarstwową systemu, zaimplementował logikę gry oraz wykonał integrację z bazą danych i frontendem. Stworzył kompletne REST API, zadbał o bezpieczeństwo aplikacji oraz konfigurację środowiska uruchomieniowego.
        Najważniejsze zadania obejmowały:
        \begin{itemize}
          \item zaprojektowanie struktury projektu backendowego oraz przepływu danych,
          \item implementację logiki biznesowej gry (sesje, rundy, punktacja, odległości),
          \item przygotowanie bazy danych oraz warstwy dostępu do danych w oparciu o Entity Framework Core i PostgreSQL,
          \item stworzenie i udokumentowanie API wykorzystywanego przez frontend PWA,
          \item integrację obsługi zdjęć miejsc wraz z mechanizmem ich przechowywania,
          \item konfigurację środowiska deweloperskiego i kontenerów Docker Compose,
          \item implementację uwierzytelniania i autoryzacji (JWT) oraz walidacji danych.
        \end{itemize}

  \item \textbf{Karina Wołoszyn} - odpowiedzialna za rozwój frontendowej części aplikacji, w tym projektowanie interfejsu użytkownika, integrację z backendem oraz systemami geolokalizacji. Do jej obowiązków należało także definiowanie wymagań projektowych oraz przeprowadzanie testów aplikacji pod kątem użyteczności i funkcjonalności.
        Najważniejsze zadania obejmowały:
        \begin{itemize}
          \item projektowanie wyglądu i układu interfejsu użytkownika,
          \item implementację funkcji interaktywnych i responsywnych elementów,
          \item integrację z backendem poprzez REST API,
          \item integrację z mapami i mechanizmami geolokalizacji,
          \item przeprowadzenie testów funkcjonalności aplikacji,
          \item notowanie i zarządzanie wymaganiami projektowymi.
        \end{itemize}
\end{itemize}
