\chapter*{Wykaz ważniejszych oznaczeń i skrótów}
\addcontentsline{toc}{chapter}{Wykaz ważniejszych oznaczeń i skrótów}

\textbf{LINQ} (ang. Language Integrated Query) - zestawu technologii opartych na integracji możliwości tworzenia zapytań bezpośrednio z językiem C\#

\textbf{SQL} (ang. Structured Query Language) - strukturalny język zapytań

\textbf{JWT} (ang. JSON Web Token) - standardowy format bezpiecznego przesyłania informacji jako obiekt JSON

\textbf{JSON} (ang. JavaScript Object Notation) - format wymiany danych oparty na składni języka JavaScript

\textbf{REST} (ang. Representational State Transfer) - styl architektoniczny wykorzystywany przy projektowaniu usług sieciowych

\textbf{API} (ang. Application Programming Interface) – zestaw reguł i protokołów określających sposób komunikacji oraz integracji pomiędzy różnymi elementami aplikacji.

\textbf{VCS} (ang. Version Control System) - system kontroli wersji

\textbf{CI/CD} (ang. Continuous Integration/Continuous Delivery lub Deployment) - zestaw praktyk tworzenia oprogramowania

\textbf{UI} (ang. User Interface) - interfejs użytkownika

\textbf{UX} (ang. User Experience) - doświadczenie użytkownika

\textbf{ITS} (ang. Issue Tracker System) - sposób zarządzania systemem, który odpowiada na zapytania wysyłane dowolną drogą.

\textbf{DTO} (ang. Data Transfer Object) - obiekt służący do przenoszenia danych między warstwami aplikacji

\textbf{ORM} (ang. Object-Relational Mapping) - technika mapowania danych między systemem obiektowym a relacyjną bazą danych
